# Santhe-Connect 🌾

Santhe-Connect is an Android application developed using Kotlin, Firebase, and Google Maps to help tourists and local users discover Karnataka’s authentic village markets, traditional food spots, and cultural experiences.

The app acts as a digital bridge between travelers and small local hospitality providers who normally do not have an online presence.

---

## 📌 Features

- 🔐 Firebase Authentication
- 🗺 Google Maps Integration
- 🍲 Local Food Discovery
- 🛍 Santhe (Weekly Market) Calendar
- 📍 Nearby Places Navigation
- ⭐ User Reviews & Ratings
- 📸 Photo Upload Support
- ➕ Add Local Place Feature
- 🔔 Push Notifications
- 🌙 Dark Mode Support
- 🌐 Kannada + English Support
